# Humble Beras

Observatory model 2026.11.0. A small interface for the stored forecast sheet and the 6 November 2026 score.

Open `index.html` in a browser, or serve this folder:

```
python3 -m http.server 8000
```

The sheet is static. Centers, bands, and the 6 November tape are the recorded ledger, not a live price feed. October employment is shown beside the sheet and labeled as Street consensus, because that print is not an Observatory path.
